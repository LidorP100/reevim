# דשבורד מעקב ביצוע בנייה

אתר למעקב ביצוע בפרויקט מגורים: מגרשים → בניינים → קומות → דירות, עם מעקב מלאכות (בוצע / לא בוצע),
גרפים, ומודל תלת מימד שנבנה לפי ציר זמן.

## מסכים

| מסך | מה יש בו |
|---|---|
| **סקירה** | אחוז ביצוע כללי, דירות שהושלמו, בניינים עם שלד גמור, קצב שבועי, כל המגרשים והבניינים, התקדמות לפי מלאכה |
| **תלת מימד** | כל האתר בתלת מימד. ציר הזמן (▶) מראה את הבניינים נבנים קומה אחרי קומה. מצבים: מציאותי / סטטוס דירה / לפי מלאכה. לחיצה על דירה מציגה את כל המלאכות שלה. חתך קומות לבניין נבחר |
| **מטריצת ביצוע** | לכל בניין: קומות ודירות × מלאכות. לחיצה על תא מסמנת בוצע עם תאריך. עדכון מרוכז לטווח קומות |
| **גרפים** | עקומת התקדמות מצטברת, קצב חודשי, התקדמות לפי מלאכה / קומה / בניין, פירוט לדירה |
| **מלאכות** | הוספה / עריכה / מחיקה של מלאכות. מלאכה חדשה נפתחת אוטומטית בכל הדירות או הקומות |
| **מבנה הפרויקט** | עריכת מגרשים ובניינים (קומות, דירות בקומה), ייבוא התפלגות מ־Excel (העתק-הדבק), גיבוי ושחזור |

ציר הזמן בראש העמוד משותף לכל המסכים — כל מסך מציג את המצב נכון לתאריך שנבחר.

## הרצה

```bash
npm install
npm run dev      # פיתוח
npm run build    # בנייה לפרסום (תיקיית dist)
```

## טכנולוגיה

React + TypeScript (Vite), Three.js (react-three-fiber), Recharts.
הנתונים נשמרים כרגע בדפדפן (localStorage) עם ייצוא/ייבוא גיבוי JSON.

## מבנה הקוד

- `src/engine.ts` — מודל הנתונים: יצירת משימות (מלאכה × יחידה), תלויות בין מלאכות, חישובי ביצוע
- `src/sample.ts` — מלאכות ברירת מחדל ונתוני דוגמה (7 מגרשים, 30 בניינים, 590 דירות)
- `src/store.tsx` — מצב האפליקציה ושמירה
- `src/views/*` — המסכים

## בהמשך

- שרת ומסד נתונים (Supabase) — סנכרון בין טלפון למחשב

- תמונות מהשטח לכל משימה
